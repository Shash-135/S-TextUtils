# TextUtils - A React Text Utility App

TextUtils is a simple and intuitive web application built with React that provides a set of tools to manipulate text. Users can perform common operations like changing case, removing extra spaces, and copying text to the clipboard, all in a clean, responsive interface with a dark mode toggle.

This project was built to practice and demonstrate fundamental concepts of React, including components, state management with `useState`, props, and event handling.

## 🚀 Features

-   **Case Conversion:** Instantly convert text to **UPPERCASE** or **lowercase**.
-   **Text Formatting:** Remove unnecessary extra spaces from your text.
-   **Clipboard Access:** Easily copy the modified text to your clipboard with a single click.
-   **Character & Word Count:** Real-time counter for words and characters.
-   **Dark Mode:** A comfortable, eye-friendly dark mode for low-light environments.
-   **Responsive Design:** Fully responsive layout for seamless use on desktops, tablets, and mobile devices.

## 🛠️ Technologies Used

-   **React.js:** For building the user interface.

## ⚙️ Getting Started

To run this project locally, follow these simple steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/shash-135/textutils.git](https://github.com/shash-135/textutils.git)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd textutils
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Start the development server:**
    ```bash
    npm start
    ```

The application will now be running on `http://localhost:3000`.
